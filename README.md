# Documentación Técnica: Infraestructura de Fibra Óptica - Internet Services SA 🌐📡

Este repositorio contiene la documentación gráfica y técnica correspondiente al diseño de red de fibra óptica para la empresa **Internet Services SA**. La información aquí presentada abarca la planificación de infraestructura en la ciudad de Santa Fe Capital y zonas de influencia.
